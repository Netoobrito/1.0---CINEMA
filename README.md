# CINE LOCAL 3.0 — Identidade cinematográfica

## Iniciar
Abra esta pasta no VS Code e execute `index.html` com a extensão Live Server.
Não há dependências de instalação. O projeto usa HTML, CSS e JavaScript.

## Páginas
- `index.html`: capa cinematográfica, catálogo visível, sessões e assentos.
- `conta.html`: cadastro/login demonstrativo.
- `checkout.html`: finalização simulada.
- `meus-ingressos.html`: ingressos registrados neste navegador.
- `admin.html`: administração demonstrativa.

## Design
Um **único `style.css`** controla todos os estilos. Paleta azul original preservada.
A apresentação e o catálogo são exibidos juntos; menu Filmes e botão Explorar filmes rolam até os cartazes.

## Limitações da demonstração
Os dados ficam no `localStorage` do navegador. Não há sincronização entre dispositivos, pagamentos reais ou autenticação segura. Nunca use senhas reais ou dados pessoais reais nesta demonstração. As imagens de pôster dependem da disponibilidade dos sites de origem. O catálogo mantém seus filmes e horários de demonstração.
